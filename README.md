# RA1 - Bodeguita (Pimentel)

Sistema de gestión para una bodega: clientes, productos, ventas y caja.
Proyecto del curso Taller de Programación de Aplicaciones (RA1).

- Nombre Apellido

## Requerimientos funcionales
RF01 Registrar cliente · RF02 Buscar cliente · RF03 Registrar producto ·
RF04 Listar y actualizar producto · RF05 Eliminar producto ·
RF06 Registrar venta · RF07 Cola de atención en caja · RF08 Historial de ventas

## Estructuras de datos
- **Cola (FIFO):** atención de ventas en caja (`ColaCajaBodeguita`)
- **Pila (LIFO):** historial de ventas (`PilaHistorialVentas`)
- **Arreglos de objetos:** clientes e inventario de productos

## Archivos
- `index.html` – interfaz y lógica de la aplicación
- `cajera.js` – cola y pila
- `productos.js` – inventario base
